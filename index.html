02 / STORAGE LAYER

Decentralized Storage

Content is addressed by what it is, not where it lives.

CONTENT ADDRESSING
CID

Content Identifiers (CIDs)

A CID is a cryptographic hash transformed into a stable content address. Identical bytes produce the same identifier, enabling global verification and deduplication.

bafybeigdyrzt...7xq2u
Input File→Cryptographic Hash→Verifiable CID
IPFSSTORAGE

IPFS

Peer-to-peer content addressing and transfer. Files are discovered across a distributed mesh by CID.

FILMARKET

Filecoin

An incentive layer where storage providers compete through retrievable capacity and cryptographic proofs.

ARPERMANENCE

Arweave

A permanent datachain designed for one-time payments and resilient, long-term archival storage.
